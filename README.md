# Schedule Maker

Модульная веб-система составления расписания вуза. Работает с тем, что обычно
ломает готовые программы: несколько городов, группы без деления на подгруппы,
преподаватели с одним доступным днём в неделю, приезжие на блок дней подряд,
занятость в стороннем учебном заведении, дистанционные пары и расписание
«через неделю».

Главное отличие от аналогов: система **объясняет, почему расписание не
складывается**, и говорит, что именно сделать, а не сообщает «решение не
найдено».

> **Соколова М. А.: нагрузка не помещается**
> Требуется 10 пар, помещается 8 пар. Доступные дни: Пн — 8 слотов, Сб — 8 слотов ·
> лимит 4 пары в день, 24 в неделю.
> *Что можно сделать: поднять дневной лимит до 5 пар; открыть ещё 1 день;
> снять 2 пары нагрузки.*

## Что умеет

**Расстановка.** Автоматическая генерация с учётом всех ограничений, ручная
правка перетаскиванием с подсветкой допустимых мест, замок на паре — генератор
обязан её сохранить, версии расписания со снимками и откатом.

**Ограничения.** 23 встроенных правила: конфликты преподавателя, группы и
аудитории, вместимость и тип аудитории, филиал и время на переезд между
городами, белые и чёрные списки дней, внешняя занятость, жёсткие временные
слоты, дневные и недельные лимиты, блок дней подряд, «окна», чередование
онлайна и офлайна. Каждое правило — отдельный плагин со своим весом от 0 до 100.

**Доступ.** Расписание групп, преподавателей и аудиторий открыто без пароля —
как на сайте вуза, с выгрузкой в календарь и версией для печати. Преподаватель
входит в личный кабинет и отправляет пожелания диспетчеру. Администрация
работает в отдельном разделе.

**Данные.** Выгрузка в XLSX, ICS и CSV, загрузка справочников из XLSX,
подключение внешнего расписания по ссылке на календарь.

## Быстрый старт

```bash
uv sync --extra dev              # или: pip install -e ".[dev]"
uv run sm db upgrade             # создать базу
uv run sm seed demo              # демонстрационные данные филиала
uv run sm serve                  # http://127.0.0.1:8000
```

Команда `seed demo` печатает пароли администратора и преподавателя — сохраните
их, повторно они не показываются.

Через Docker:

```bash
docker compose up --build        # http://localhost:8000
```

## Что попробовать в демо-данных

Демонстрационная база воспроизводит реальную ситуацию филиала, включая
заведомо неразрешимый случай — чтобы сразу было видно, как работает
диагностика.

| Что открыть | Что увидеть |
|---|---|
| `/admin/diagnostics` | Перегруженный преподаватель и совет, что сделать |
| `/admin/builder` | Сетка с перетаскиванием, панель нерасставленных, замки |
| Потащить пару в конструкторе | Зелёным — куда можно, красным — куда нельзя и почему |
| `/admin/constraints` | 23 типа правил; форма настройки рисуется из описания плагина |
| `/admin/plugins` | Выключить правило и перегенерировать — счёт изменится |
| `/` без входа | Расписание групп, `.ics` для телефона, версия для печати |
| `/me` под логином преподавателя | Своя нагрузка и форма пожеланий |

## Команды

```bash
sm db upgrade            # применить миграции
sm db reset --yes        # пересоздать базу (данные теряются)
sm seed demo             # демонстрационные данные
sm admin create --login  # создать администратора
sm check                 # предполётная диагностика в терминале
sm generate --seed 42    # сгенерировать расписание
sm plugins               # список плагинов
sm serve --reload        # веб-сервер
```

## Настройки

Переменные окружения с префиксом `SM_` (или файл `.env`):

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `SM_DATABASE_URL` | `sqlite:///./schedule.db` | Строка подключения; работает и PostgreSQL |
| `SM_SECRET_KEY` | `dev-secret-change-me` | Подпись сессий — **обязательно поменять** |
| `SM_DAYS_PER_WEEK` | `6` | Учебных дней в неделе |
| `SM_SLOTS_PER_DAY` | `8` | Пар в дне |
| `SM_SOLVER_KEY` | `solver.greedy` | Движок генерации по умолчанию |
| `SM_SOLVER_SEED` | `42` | Зерно случайности: одно зерно — один результат |
| `SM_DISABLED_PLUGINS` | — | Ключи плагинов через запятую; сильнее настройки в БД |
| `SM_SEED_DEMO` | `0` | `1` — залить демо-данные при первом запуске |

## Устройство

Подробности — в [ARCHITECTURE.md](ARCHITECTURE.md). Коротко: ядро не знает ни
одного конкретного правила расписания. «Преподаватель не может вести две пары
одновременно» — такой же плагин, как и любое правило, которое понадобится
завтра. Как написать своё правило за тридцать строк — в
[PLUGINS.md](PLUGINS.md).

```
Веб (FastAPI + Jinja2 + htmx + Tabler)
  ↕
Сервисы (сборка задачи · диагностика · генерация · версии)
  ↕
Реестр плагинов (правила · движки · выгрузка · источники · интерфейс)
  ↕
Модели (SQLAlchemy) → SQLite или PostgreSQL
```

## Разработка

```bash
uv run pytest            # тесты
uv run ruff check .      # линтер
uv run ruff format .     # форматирование
uv run mypy              # типы
```

Сборка и релиз — один workflow `.github/workflows/ci.yml`: push и pull request
гоняют линтеры, тесты и сборку, тег `vX.Y.Z` дополнительно публикует релиз
с колесом и образ в GHCR.
