# Своё правило расписания

Рабочий пример стороннего расширения: правило «по пятницам не ставим поздние
пары». Скопируйте каталог, переименуйте пакет — и пишите своё.

## Установка

```bash
pip install -e examples/plugin_template
sm plugins | grep local.no_late_friday
```

Правило появится в разделе «Ограничения» панели управления: с названием,
описанием, формой настройки и ползунком веса. Ядро программы при этом не
меняется ни одной строкой.

## Из чего состоит

| Файл | Что в нём |
|---|---|
| `pyproject.toml` | Точка входа `schedule_maker.plugins` — только благодаря ей ядро находит плагин |
| `my_schedule_rules/rules.py` | Само правило и подписка на событие `after_generate` |
| `tests/test_rules.py` | Тесты без базы: правилу нужны только структуры предметной области |

## Как это работает

Реестр при запуске перебирает точки входа группы `schedule_maker.plugins` и
берёт из каждого модуля либо список `PLUGINS`, либо функцию
`register(registry)`. Дальше плагин живёт наравне со встроенными: его можно
выключить на странице «Плагины», настроить на странице «Ограничения», а его
запреты одинаково действуют и в генераторе, и при перетаскивании пары мышью.

## Что ещё можно расширять

Кроме правил, теми же точками входа подключаются движки генерации,
выгрузка и загрузка данных, источники внешних расписаний и целые страницы
интерфейса. Полный список контрактов с примерами — в `PLUGINS.md` в корне
репозитория.
