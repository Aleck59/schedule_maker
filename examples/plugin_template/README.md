# Своё расширение для Schedule Maker

Скопируйте этот каталог, переименуйте пакет — и у вас есть заготовка
собственного правила, алгоритма, импортёра, экспортёра или отчёта.

## Как это работает

Ядро программы не знает ни одного плагина по имени. Оно читает точки входа и
подключает всё, что найдёт. Поэтому ваш пакет становится частью программы после
обычной установки, а удаляется — обычным удалением.

```toml
[project.entry-points."schedmaker.constraints"]
my_rules = "my_schedule_rules.rules:register"
```

Точка входа указывает на функцию `register()` без аргументов, которая
возвращает один плагин или список.

## Доступные точки расширения

| Группа | Что добавляет | Что нужно реализовать |
|---|---|---|
| `schedmaker.constraints` | правило расписания | `check` или `evaluate` |
| `schedmaker.solvers` | алгоритм составления | `solve` |
| `schedmaker.importers` | загрузку исходных данных | `preview`, `load` |
| `schedmaker.exporters` | выгрузку расписания | `export` |
| `schedmaker.reports` | отчёт | `build` |
| `schedmaker.external` | чужое расписание (колледж) | `busy_slots` |

Точные сигнатуры — в `schedmaker/plugins/api.py`.

## Правило: две скорости проверки

* `check(tt, placement)` смотрит на одно назначение и стоит несколько операций.
  Именно он подсвечивает конфликты, пока пользователь тащит пару мышью.
* `evaluate(tt)` видит всё расписание целиком — он нужен требованиям вида
  «дни идут подряд» или «не больше одного окна в день».

Наследник `BaseConstraint` может реализовать только `check` — тогда `evaluate`
получится сам. Правилу с общей картиной проще переопределить `evaluate` и
объявить `scope = ConstraintScope.GLOBAL`; при этом можно дополнительно
реализовать `check` как быструю частичную проверку.

## Текст важнее логики

`message` читает диспетчер учебной части, а не программист. Пишите так, как
объяснили бы коллеге: с именами, числами и без терминов. В `hint` кладите
действие, которое исправит положение.

Плохо: `Ошибка ограничения teacher.days`
Хорошо: `Гаджиев М. А. не работает в среду; доступные дни — сб.`
+ подсказка `Перенесите пару на сб или расширьте список дней.`

## Проверка

```bash
pip install -e examples/plugin_template
schedmaker plugins          # правило и отчёт должны появиться в списках
```

Затем откройте «Правила» в панели управления: новое правило можно включать,
смягчать и настраивать наравне со встроенными.
