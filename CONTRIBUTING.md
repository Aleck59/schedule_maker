# Как дорабатывать

## Окружение

```bash
uv sync --extra dev
uv run sm db upgrade
uv run sm seed demo
uv run sm serve --reload
```

## Перед отправкой изменений

```bash
uv run ruff check .        # линтер
uv run ruff format .       # форматирование
uv run mypy                # типы
uv run pytest              # тесты
```

Ровно это же гоняет CI, так что зелёный локальный прогон означает зелёный
прогон в репозитории.

## Куда класть изменения

| Что меняется | Куда идти |
|---|---|
| Новое правило расписания | Плагин — см. [PLUGINS.md](PLUGINS.md), ядро трогать не нужно |
| Поле в справочнике | Одна строка в списке `fields` в `web/routers/admin_catalog.py` |
| Новая страница | `web/routers/` + шаблон, либо `UIPlugin` без правки ядра |
| Вид карточки пары | Макрос `lesson_card` в `templates/partials/ui.html` — он один на всё приложение |
| Поле в базе | Модель в `models/`, затем `uv run alembic revision --autogenerate -m "..."` |

## Правила, которые стоит соблюдать

**Плагины не ходят в базу.** Им передаётся готовый снимок `Problem`. Если
правилу не хватает данных — добавьте поле в `domain.py` и заполните его в
`services/problem_builder.py`.

**Текст ошибки пишется для человека.** Не «constraint violation», а
«Магомедов А. Г. не работает в это время (Пн, 1 пара). Может: Сб». Если можно
подсказать, что сделать, — подскажите.

**Проверка одна на всех.** Генератор и перетаскивание спрашивают один и тот же
движок правил. Не добавляйте отдельную проверку в веб-слой: то, что запрещено
в генераторе, должно быть запрещено и руками, и наоборот.

**Русские названия в интерфейсе, английские в коде.** Имена полей, методов и
ключей плагинов — латиницей; всё, что видит пользователь, — по-русски.

## Миграции

```bash
uv run alembic revision --autogenerate -m "Описание"
uv run alembic upgrade head
```

Проверьте сгенерированный файл глазами: автогенерация не всегда угадывает
переименования.

## Релиз

```bash
git tag v0.2.0
git push origin v0.2.0
```

Тег запускает в том же workflow сборку релиза: колесо и исходники прикладываются
к GitHub Release, образ уходит в GHCR.
